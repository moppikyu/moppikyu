## Featured Project — VisioSphere

<div align="center">
<sub>Real-time fall, agitation & inactivity monitoring for care facilities</sub>
</div>
<br/>

**Backend — my scope**
- Node.js + Express 5 REST API
- Socket.IO for real-time alert broadcasting
- MongoDB / Mongoose data layer
- JWT authentication
- Firebase Cloud Messaging for push alerts
- AWS S3 for clip storage
- Scheduled reporting via node-cron

**Frontend — my scope**
- React 19 + Vite 7 live-monitoring dashboard
- Tailwind CSS + MUI
- socket.io-client for live alerts
- Recharts / MUI X Charts for incident statistics
- jsPDF for report export

> The AI detection core (YOLO11-pose, OpenVINO, ByteTrack) was built by a collaborating teammate — my contributions are the alert pipeline and the dashboard that consumes it.
